# みなと不動産（デモサイト）

不動産会社のホームページのデモです。GitHub Pages で公開しています。

## ページ構成

| ページ | ファイル | 内容 |
| --- | --- | --- |
| ホーム | `index.html` | ご用件別の入口、選ばれる理由、お知らせ |
| 借りたい | `rent.html` | 賃貸物件一覧（PDF資料）＋物件情報アップロード |
| 買いたい | `buy.html` | 売買物件一覧（PDF資料）＋物件情報アップロード |
| 売りたい | `sell.html` | 売却方法、売却の流れ、必要書類、FAQ |
| 事業用地 | `land.html` | 取扱内容、取扱物件、相談から契約までの流れ |
| 会社概要 | `company.html` | ごあいさつ、会社情報、沿革、お問い合わせ、アクセス |

## PDFアップロード機能について

「借りたい」「買いたい」ページで、PDF形式の物件資料をユーザー自身で登録できます。

- ドラッグ＆ドロップ／ファイル選択に対応（PDFのみ・10MBまで）
- 物件名・賃料／価格・所在地・交通・間取り・面積・備考を入力して登録
- 登録した物件は一覧にカード表示され、「PDFを見る」で別タブ表示、「削除」で削除

**現在の保存先はブラウザ内の IndexedDB です。** GitHub Pages は静的ホスティングでサーバー処理を持たないため、
アップロードしたファイルは外部に送信されず、登録した端末・ブラウザからのみ閲覧できます。
複数人で共有する運用にする場合は、以下のいずれかへの置き換えが必要です。

- サーバー／BaaS（例：Cloudflare R2 + Workers、Firebase Storage、S3 + Lambda）へ保存し、管理者ログインを追加する
- PDFをリポジトリにコミットし、一覧データ（JSON）を更新する運用にする
