# みなと不動産（デモサイト）

不動産会社のホームページのデモです。GitHub Pages で公開しています。

公開URL：https://yasufumi-27.github.io/real-estate-company/

## ページ構成

| ページ | ファイル | 内容 |
| --- | --- | --- |
| ホーム | `index.html` | ごあいさつ、ご用件別の入口、当社の特長、お知らせ |
| 借りたい | `rent.html` | 賃貸物件一覧（PDF資料付き）、ご契約までの流れ |
| 買いたい | `buy.html` | 売買物件一覧（PDF資料付き）、ご購入までの流れ |
| 売りたい | `sell.html` | 売却方法、売却の流れ、必要書類、FAQ |
| 事業用地 | `land.html` | 取扱内容、取扱物件、相談から契約までの流れ |
| 会社概要 | `company.html` | 会社情報、沿革、お問い合わせ、アクセス |
| 物件情報の更新 | `admin.html` | 担当者用。物件の追加・書きかえ・削除・並べかえ |

街並みのバナー・黒い横並びナビ・左サイドバー付きの2カラム・淡いグリッド壁紙。

## 物件情報の更新のしくみ

### 担当者の方の操作（`admin.html`）

パソコン操作に不慣れな方を想定し、専用アプリもコマンド操作も不要な**ブラウザ内の更新画面**にしています。

- 「借りたい」「買いたい」をボタンで選ぶ → 物件を選んで「内容を書きかえる」→「この内容で保存する」の3ステップ
- 新規追加、削除、並べかえ（↑上へ／↓下へ）、PDF資料の登録・入れかえ
- 必須入力は物件名のみ。入力欄ごとに記入例を常時表示
- エラーは「何がだめで、どうすれば直るか」を日本語で表示（例：PDF以外を選んだとき、10MB超のとき）
- 削除時は物件名を出して確認
- 操作マニュアル（PDF・全13ページ・画面写真つき）：`assets/pdf/manual.pdf`

保存先はブラウザ内の IndexedDB です（GitHub Pages は静的公開でサーバー処理を持てないため）。
つまり保存しただけでは、その担当者のパソコンにしか反映されません。

### 公開ページに反映する流れ

1. 担当者が `admin.html` で編集し、**「物件データを書き出す」**を押す
   → `物件データ_YYYY-MM-DD.json`（PDFも含む1ファイル）がダウンロードされる
2. そのファイルをメール添付でサイト管理者へ送る
3. サイト管理者が受け取ったファイルを **`data/properties.json` として置き換えてコミット・push**
4. GitHub Pages に反映され、全訪問者に見える

公開ページ（`rent.html` / `buy.html`）は `data/properties.json` を読んで表示します。
`admin.html` の「ホームページでの見え方を確認する」は `?preview=1` 付きで開き、
その端末で編集中の内容をプレビュー表示します（公開内容とは別）。

### 検討した他の方式（不採用の理由）

| 方式 | 不採用の理由 |
| --- | --- |
| AIチャットに話しかけて更新 | 言い換えが必要な場面が多く、どこが変わったか確認しづらい。費用も継続発生 |
| エクセル＋バッチ処理 | ファイル操作・CSV保存形式の理解が必要。文字化けや手順の途中脱落が起きやすい |
| サーバー保存（Firebase等） | 操作は同じまま将来移行可能。まずは追加費用ゼロの上記方式で運用に慣れてから |

将来サーバー保存へ移行する場合も、`admin.html` の画面と操作手順はそのまま使えます
（保存先を差し替えるだけ）。

## ファイル構成

```
index.html / rent.html / buy.html / sell.html / land.html / company.html
admin.html                担当者用の更新ページ
data/properties.json      公開中の物件データ（これを差し替えると公開内容が変わる）
assets/css/style.css      サイト共通スタイル
assets/css/admin.css      更新ページ専用スタイル（大きめの文字・ボタン）
assets/js/site.js         メニュー開閉など
assets/js/properties.js   物件データの読み書き・一覧表示
assets/js/admin.js        更新ページの処理
assets/img/banner.svg     ヘッダーの街並みイラスト
assets/pdf/manual.pdf     操作マニュアル（担当者向け）
assets/pdf/*-sample-*.pdf 物件概要書のサンプル
```
